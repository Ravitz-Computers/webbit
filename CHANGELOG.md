# Changelog

## Beta 1 — September 30, 2026

- Alt-drag selects elements touched by the rectangle; Shift+Alt adds to the selection. Groups stay together, and Escape cancels.
- Ctrl-click opens local project pages, including fragments. External HTTP/HTTPS links require confirmation before opening in the default browser. Ctrl-drag still rotates.
- Stabilized split-view sizing and interface scaling. Repaired element context menus and ruler hide commands.
- Interface scaling defaults to 85%; saved preferences remain respected.
- Added concise free-tool and AI-assisted side-project attribution in README and About.
- Packaged Windows installer, portable runtime and source; 239 automated checks and 12 browser interaction checks passed.

See STATUS.md for remaining limitations and DEVELOPMENT.md for the earlier feature history.
