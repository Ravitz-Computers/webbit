## Access and encryption update

Use Ribbon > Access for separate administrator and member login configuration. Member Access saves webbit.access.json locally; this metadata is excluded from public exports. Enable login and select HTML pages, then export to generate PHP routes. Read README-MEMBERS.md inside the export before deployment. Encryption of authenticator secrets is automatic; it does not encrypt page files or shared assets. Passwords and recovery codes are hashes. Back up private keys with account databases in encrypted backup storage.

The file browser supports type filters and sorting. Preview offers Desktop, Tablet, Phone and Reading. The searchable Element Gallery includes restaurant menus, schedules, pricing and optional live Google Reviews. Draw a rectangle to place an element; use the Canvas selector to move or resize. Pixel positioning needs responsive review. Google Reviews requires a paid-capable Google API account and PHP hosting; the core editor remains free of required external services.
