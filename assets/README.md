# Included artwork

The original HARE/Ravitz PNGs and SVGs under public/hare are proprietary artwork; see PROPRIETARY-ASSETS.md and provenance.json. The app uses original SVG poses and the full-detail medallion logo, preserving fills, gradients and natural proportions. The PNG originals remain available unchanged.

assets/webbit-icon.svg wraps logo-no-words.svg in a padded square using xMidYMid meet. Generate Windows icons with `pnpm tauri icon assets/webbit-icon.svg`. The wrapper contains real paths, not an enlarged thumbnail. No artwork download is required to build.
